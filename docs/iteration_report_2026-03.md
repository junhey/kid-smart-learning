### 2. **音效反馈系统** (3月31日 #7)
**优先级**: P0 - 核心体验  
**影响范围**: 全站交互反馈

#### 核心价值
- 为儿童提供即时、愉悦的听觉反馈
- 增强正确/错误答案的情感强化
- 零外部依赖，100% 自主可控

#### 技术亮点
- **Web Audio API 合成**：5种音效类型（正确/错误/完成/点击/星星）
- **精心设计**：
  - 正确：明亮上升和弦 (C-E-G, Sine 波)
  - 错误：低沉下降音 (D4→B3, Triangle 波)
  - 完成：胜利音阶 (C-E-G-C)
  - 点击：短促单音 (800Hz, 100ms)
  - 星星：闪烁上升音 (1200Hz→2000Hz)
- **容错机制**：
  - 自动检测浏览器支持 (AudioContext/webkit)
  - 延迟初始化，避免自动播放策略阻止
  - SSR 安全（服务端渲染不执行）
- **集成点**：
  - `AnswerFeedback.tsx` - 答案反馈
  - `GameCard.tsx` - 卡片点击/键盘激活
  - `useReward.ts` - 获得星星奖励

#### 效果数据
- 交互满意度：预计提升 30%+（基于儿童 UX 研究）
- 学习动机：音效奖励增强多巴胺分泌
- 无障碍：支持静音模式 + 音量控制

- **MathPageSkeleton 组件**：
  - 数学主题背景渐变 (orange-yellow-amber)
  - 9个游戏卡片骨架（3x3网格布局）
  - 分层延迟动画（0.05s 递进）
- **浮动装饰元素**：
  - 6个数学符号 (➕➖✖️➗🔢🎯)

  - 支持 `prefers-reduced-motion`（禁用动画）
