## 问题识别

用户（儿童）缺乏「这一周我学了多少」的宏观视角。现有的打卡火焰只展示连续天数，但不能直观反映「本周 7 天中哪几天有学习」。研究表明，对儿童来说，可视化的「集齐」机制（类似集贴纸）比纯数字更有吸引力。

## 方案

新增 `WeeklyProgress` 组件，包含：
1. **SVG 圆环进度条** — 渐变描边 (indigo → purple)，动画填充
2. **7 个星期指示圆点** — active 日显示 ✓ + 渐变背景，inactive 显示星期缩写
3. **鼓励文案** — 根据活跃天数动态切换（🌱→💪→🌟→🏆）
4. **localStorage 持久化** — 按周重置，记录每天访问

## 实现细节

- 组件路径：`components/ui/WeeklyProgress.tsx`
- 集成位置：首页 Streak 区域下方、每日任务上方
- 动画策略：进度环 1.2s ease-out + 圆点 stagger 0.06s
- 无障碍：`role="region"` + `aria-labelledby` + reduced-motion 零动画 fallback
- 周重置逻辑：以周一为起点，`getWeekStart()` 比对决定是否清零
