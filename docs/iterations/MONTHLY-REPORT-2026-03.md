## 🎓 经验沉淀

### 本次学到的
1. **骨架屏设计黄金法则**
   - 布局必须 1:1 还原，否则会有"跳"的感觉
   - 动画速度 1.5s 最佳（不快不慢）
   - 过渡时间 800ms 给数据加载留余量

2. **性能优化思路**
   - GPU 加速动画 > CSS animation
   - 及时卸载不需要的组件释放内存
   - 骨架屏也要有"品牌感"，不能太生硬

3. **用户体验原则**
   - 永远不让用户看到"内容突然跳进来"
   - 感知速度 > 实际速度
   - 一致性 > 炫技
